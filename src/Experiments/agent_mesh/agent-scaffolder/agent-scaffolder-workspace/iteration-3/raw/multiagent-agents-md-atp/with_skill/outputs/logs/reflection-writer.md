# Reflection Log — Writer (Scribe)

Cadence destination: append a summary every 10 revisions or at session end. Capture what
shipped, recurring feedback themes, and any open conflicts. (Inline one-line self-checks
live in the response itself, not here.)

Entry format:

```
## Reflection — <ISO date/time>  (through rev <n>)
- Attempted: <what was drafted/revised>
- Assumptions: <any necessary assumptions, or "none">
- Drift check: <stayed within mission/boundaries? note exceptions>
- Recurring feedback: <themes seen across reviews>
- Next: <follow-ups, if any>
```
